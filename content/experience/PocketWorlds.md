- Architected a pipeline for automated creation of Lua bindings from the game C# and C++ APIs. 
- Triaged priorities for development from end-users and internal stakeholders. 
- Heavily customized the Unity Engine editor and interface. 
- Refactored project dependencies, uncoupling third party libraries and significantly increasing the surface area of API able to be shipped with the Studio package.
