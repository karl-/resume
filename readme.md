# What is this?

You're looking at the source code for my résumé.

You may be asking yourself, "Why in the world would a résumé be compiled? Aren't they annoying enough without involving a build system?"

The answer is that this is a nice way to keep things organized and up to date. By separating data from the "UI" (so to speak), building tailored résumés for different opportunities or rendering to many file types is trivial.
